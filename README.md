<small>**🍽️ Restaurant Management System**</small>

<small>Welcome to my Restaurant Management System repository. This desktop application was developed using C# and Windows Forms as part of the Object-Oriented Programming 2 (OOP2) course. It provides a complete solution for managing restaurant operations efficiently.</small>

<small>**✨ Key Features**</small>

<small>**1. Role-Based Access Control:**</small>
- <small>**Owner Dashboard:** Full access to manage employees, products, categories, discounts, and view complete order and payment histories.</small>
- <small>**Employee Dashboard:** Access to view products, manage categories, and handle daily order and payment histories.</small>

<small>**2. Menu & Product Management:**</small>
- <small>Add, update, delete, and categorize food items and products.</small>
- <small>Manage menu information and details.</small>

<small>**3. Order & Payment Tracking:**</small>
- <small>Keep track of customer orders and payment methods.</small>
- <small>View detailed payment and order histories.</small>

<small>**4. Employee Management:**</small>
- <small>Owners can add, monitor, and manage employee profiles.</small>
- <small>Maintain secure system access and roles.</small>

<small>**5. Discount & Promotional System:**</small>
- <small>Create, manage, and apply custom discount codes.</small>
- <small>Track claimed discounts and promotions.</small>

<small>**🛠️ Technologies Used**</small>
- <small>**Language:** C#</small>
- <small>**Framework:** .NET Framework (Windows Forms / WinForms)</small>
- <small>**IDE:** Visual Studio</small>
- <small>**Architecture:** Object-Oriented Programming (OOP) principles</small>

<small>**🚀 How to Run**</small>
<small>Open the `Restaurant Management System.csproj` file in Visual Studio, configure it if necessary, build the solution, and run the application. Alternatively, clone or download this repository to your local machine before opening it in the IDE.</small>
